## Accessibility & Keyboard Navigation (Focus Trap)

### Keyboard Shortcuts Guide:


| Form Element | Navigation Key | Interaction |

| **Close Button (X)** | `Tab` / `Shift + Tab` | Press `Enter` or `Space` |
| **Text Inputs** (Name, Age, Email...) | `Tab` / `Shift + Tab` | Type directly |
| **Autocomplete** (Country) | `Tab` / `Shift + Tab` | Type to filter. Use `ArrowUp` / `ArrowDown` to navigate, `Enter` to select |
| **Radio Buttons** (Gender) | `Tab` / `Shift + Tab` | Change option using `ArrowLeft` / `ArrowRight` |
| **Checkbox** (I agree) | `Tab` / `Shift + Tab` | Toggle state using `Space` |
| **Action Buttons** (Password toggles, Submit) | `Tab` / `Shift + Tab` | Press `Enter` or `Space` |
