# React + TypeScript + Vite 

This is the sample setup, created with Vite and for the purposes of showing the bare minimum required for the React application. Should be used for the educationla purposes for the [RS React Cours](https://rs.school/courses/reactjs).


## Testing

To run the full test suite with coverage report:

```bash
npm test
```

Alternatively, you can run Vitest directly:

```bash
npx vitest run --coverage
```
