## Accessibility & Keyboard Navigation (Focus Trap)

### Keyboard Shortcuts Guide:

- **Close Button (X)**
  Move focus: `Tab` / `Shift + Tab` | Interact: Press `Enter` or `Space`

- **Text Inputs** (Name, Age, Email...)
  Move focus: `Tab` / `Shift + Tab` | Interact: Type directly

- **Autocomplete** (Country)
  Move focus: `Tab` / `Shift + Tab` | Interact: Type to filter. Use `ArrowUp` / `ArrowDown` to navigate, `Enter` to select

- **Radio Buttons** (Gender)
  Move focus: `Tab` / `Shift + Tab` | Interact: Change option using `ArrowLeft` / `ArrowRight`

- **Checkbox** (I agree)
  Move focus: `Tab` / `Shift + Tab` | Interact: Toggle state using `Space`

- **Action Buttons** (Password toggles, Submit)
  Move focus: `Tab` / `Shift + Tab` | Interact: Press `Enter` or `Space`
